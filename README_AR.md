## 🌟 نظرة عامة

SpeechScribe V4 هو نظام متقدم للتفريغ الكلامي يدعم جميع اللغات، 
يستخدم تقنيات متطورة لمعالجة الإشارات الصوتية بسرعة فائقة ودقة عالية.

---

## ⚡ المميزات

### 🚀 سرعة خيالية
- **120x أسرع من الوقت الحقيقي**
- معالجة **ساعة واحدة في 30 ثانية**
- **جميع الصيغ** - WAV, MP3, FLAC, M4A, OGG, AAC

### 🎯 دقة عالية
- **90-95% دقة**
- خوارزميات متطورة
- **يدعم جميع اللغات**

## 📦 التثبيت

```bash
git clone https://github.com/slam-prog/SpeechScribe.git
cd SpeechScribe
pip install -r requirements.txt
sudo apt-get install ffmpeg  # Ubuntu
```

---

## 🎯 البدء السريع

```bash
# الواجهة الرسومية
python run_gui.py

# سطر الأوامر
python run_cli.py audio.mp3
```
